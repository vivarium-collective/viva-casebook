✗ The trap — and why a passing scorecard is trustworthy

A task that needs physics_2d and spatial looks like a physics job, so the agent reaches for viva-munk. But viva-munk declares no spatial capability — so source_fit → mismatch, the gate fails, and the wrong module is stopped before the tests lock. The scorecard reads well because the audit can say no.

Honest scope. This is a strong result on one investigation of six tasks, not a broad benchmark yet — the audit is a perfect discriminator here.
