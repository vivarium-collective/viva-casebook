Data-grounded biology — break & repair by parameter estimation

A kinetic model run in the real COPASI backend; one parameter is broken and must be repaired against the intact reference time-course. The repair oracle is optimization, not recall — COPASI Parameter Estimation fits the reference trace and recovers the true value, and a recall-free localization baseline fits all candidates and identifies the broken one by which must move. Break ids are opaque and the reference + broken traces are shown, so the diagnosis cannot come from a memorized number.

The AUTHOR phase — author + audit + lock its own tests

The loop's real novelty: from an open question, acceptance tests are written, a hardened audit RUNS degenerate null models to check the tests reject them (executable, not a label), the tests are locked with a pre-registration hash that build() re-verifies, then a model is built that passes them. This panel is a deterministic demonstration of the audit→lock→build machinery — no LLM in the loop; every verdict is real output of author_tests_task.py.

Full cycle: question → author → hardened audit → lock → build

✓ built · 4/4 tests passaudit: sufficientlock sha256 6e00522c2c…min/max bounded
A final-only band is insufficient (the audit shows spike/dip nulls slip through), so the suite adds max<=5.5 (rejects transient blow-up) and min>=-0.5 (rejects a negative excursion). That bounded suite passes the audit; locked; a first-order relaxation Process then converges boundedly to 5 -> all tests pass.
🔎 The audit rejects a plausible-looking suite. A final-only band (final≥4.5, final≤5.5) looks reasonable — but the hardened audit RUNS transient nulls and flags that spike_then_settle, dip_then_settle slip through: a model that spikes to 10⁶ mid-run and settles to ~5 passes a final-only test while violating "stays bounded". So the suite cannot lock until it also bounds max and min. And the lock is enforced: editing the locked tests after pre-registration makes build() refuse to grade (hash mismatch). Not a classification label, not a promise.
