Interesting biology — BioModels break-and-repair

A curated BioModels model (Elowitz 2000 repressilator) run in the real COPASI backend. One kinetic parameter is broken; the agent must diagnose which and repair it against the intact reference — objective ground truth, not an author-set band, answer not in the prompt. Three distinct breaks, each diagnosed first-try with different reasoning.

Broken: n — the cooperative-repression Hill coefficient

✓ repaired in 1 stepn: 1.0 → 2.0rmsd → 0.0
Cross-checked parameter internal consistency (decay constants = ln(2)/half-life; three leakiness ratios self-consistent → untampered). n=1.0 was the only uncorroborated AND dynamically critical parameter: the alpha=216/beta=0.2 regime needs cooperative repression (n=2) to cross the Hopf bifurcation into sustained oscillation. Set n=2.

Broken: KM — the repression half-saturation constant

✓ repaired in 1 stepKM: 80.0 → 40.0rmsd → 0.0
KM=80 is exactly double the canonical Elowitz repressilator value (40); every other parameter matched textbook values. A doubled repression threshold detunes/damps the oscillation. Singled out KM as the outlier; set KM=40.

Broken: translation efficiency — the translation efficiency (proteins per transcript)

✓ repaired in 1 steptranslation efficiency: 10.0 → 20.0rmsd → 0.0
translation efficiency=10 is half the canonical 20 and inconsistent with the derived k_tl constant + other translation kinetics; all other params matched repressilator magnitudes. Restored to 20.

The AUTHOR phase — agent authors + audits + locks its own tests

The loop's real novelty: from an open question the agent writes acceptance tests, a hardened audit runs degenerate null models to check the tests reject them (executable, not a label), the tests are locked with a pre-registration hash, then the agent builds a model that passes them.
